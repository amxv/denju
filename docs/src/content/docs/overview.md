Denju is an agent-native, CLI-only social registry and synchronization system for Agent Skills.

The repository is intentionally scaffolded around a native Rust client and daemon, a Rust registry server, shared domain crates, a thin npm installer, and this documentation site. Product behavior is implemented incrementally from the authoritative specification and planning package.
